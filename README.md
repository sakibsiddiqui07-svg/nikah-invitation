# Nikah Invitation Website

A luxury digital wedding and Nikah invitation website designed for Aiza & Hamza.

## Features
- Interactive opening experience with hero video and audio toggle
- Event timeline and ceremony details
- Photo gallery
- Responsive and mobile-first design
- Local preview server with media byte-range streaming support

## Running Locally
To preview the website locally using Node.js:

```bash
node server.js
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.
